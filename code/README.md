# Code

This directory contains the original SAS code developed for the **PH 1820 – Applied Linear Regression** final project.

The analysis includes:

- Data import and preparation
- Exploratory data analysis
- Multiple linear regression
- Regression diagnostics and assumption checks
- Influence diagnostics
- Box–Cox transformation assessment
- Log transformation of the response
- Partial F testing
- Interaction assessment
- Best-subsets and stepwise model selection
- Final model estimation and diagnostics
- PRESS validation
- Confidence and prediction intervals
- Bonferroni simultaneous confidence intervals

The original SAS code has been preserved without modification from the completed course project.

For an overview of the analysis and key findings, see the main [`README.md`](../README.md).
