# Presentation

This directory contains the final presentation for the **PH 1820 – Applied Linear Regression** project.

The presentation provides an overview of the:

- Research question and study variables
- Data preparation and exploratory analysis
- Initial multiple linear regression model
- Model diagnostics and influence assessment
- Box–Cox transformation and selection of `log(nodes + 1)`
- Partial F test and interaction assessment
- Best-subsets and stepwise model selection
- Final regression model and interpretation
- Model validation and Bonferroni-adjusted inference
- Main findings and limitations

For a detailed overview of the project and key results, see the main [`README.md`](../README.md).
